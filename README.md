# 电化学数据分析工具集（C 语言实现）

> 这个项目 = 一份简历项目 + 一次 408 知识落地 + BMS 面试的核心谈资。
> 全部纯 C 写成，没有第三方库，两个模块共约 500 行。

本项目包含**两个模块**，覆盖两种电化学储能器件、两类数值方法：

| 模块 | 器件 | 数据来源 | 核心算法 | 产出 |
|---|---|---|---|---|
| **一** `liion_cycle.c` | 锂离子电池（液态 / 固态电解质各一） | **本人处理的恒流充放电(GCD)实测数据** | 充放电配对 + 库仑效率 / 容量保持率 / 极化电压 | 逐循环性能表、液态 vs 固态对比 |
| **二** `cv_capacitance.c` | 水系电解液超级电容器 | **本人 CHI600E 实测原始数据**（4000 点 × 12 组） | 梯形法则数值积分 | 电容值、倍率性能、电解液筛选 |

> 两个模块用的都是**自己进实验室亲手测 / 亲手处理的数据**，不是下载来的——面试时能说出"这台仪器我上手过、这些曲线是我跑的、这些数据是我导出来处理的"，说服力比纯公开数据集再高一级。

  - **固态电解质电池（= Sheet2，用户凭记忆确认）**：导出数据以 4 条放电曲线为主（充电曲线导出不完整、电压窗口偏窄 2.4–3.0 V），仅能做放电层面的分析

## 一、这个项目做什么

BMS（电池管理系统）最核心的算法问题就是：**怎么知道电池还剩多少电（SOC）？怎么判断电池在衰减？** 两个模块分别用真实电化学数据练习这两件事：

**模块一（锂离子电池 GCD）**：从恒流充放电曲线里提取关键循环指标——
1. **库仑效率 CE** = 放电容量 ÷ 充电容量（每圈算一次，首圈低、稳定后趋近 100%）
2. **容量保持率** = 第 N 圈放电容量 ÷ 首圈放电容量（量化衰减）
3. **极化电压 ΔV** = 充电中点电压 − 放电中点电压（评估内阻 / 极化）

```
本人 GCD 实测数据（Excel → 导出为每条曲线一个 CSV）
        │
        ▼
 ① 读取（解析文件名_CH/_DI，动态数组存 比容量/电压）
        │
        ▼
 ② 分类（电压随容量上升=充电，下降=放电）+ qsort 按列序排
        │
        ▼
 ③ 配对（充电→其后紧邻放电 合成一个循环；并做同循环校验）
        │
        ▼
 ④ 计算（线性插值求 50% 容量处中点电压；逐循环 CE / ΔV）
        │
        ▼
 ⑤ 汇总（平均 CE、平均 ΔV、放电容量保持率；液态 vs 固态对比）
```

**真实数据运行结果（液态电池）**：首圈 CE 89.2% → 稳定 99.3%，平均 97.0%；放电容量保持率 94.5%（85.80 → 81.10 mAh/g）；平均极化电压 0.152 V。

> 固态电池因充电曲线导出不完整、且与放电曲线电压窗口不自洽，程序会**自动判定"无对应充电"**，只输出放电容量与保持率（95.9%），不编造库仑效率——这本身就是处理真实脏数据该有的严谨。

**模块二（超级电容器 CV）**：见第五章。

## 二、怎么编译运行

电脑上装了 MinGW（gcc）即可，在项目目录打开命令行：

```bash
# 模块一：锂离子电池 GCD 循环分析（本人实测数据）
gcc -O2 -Wall -o liion_cycle.exe liion_cycle.c -lm
./liion_cycle.exe liion_data/liquid        # 只分析液态电池
./liion_cycle.exe liion_data/liquid liion_data/solid   # 液态 + 固态 对比

# 模块二：超级电容器 CV 电容分析（本人实测数据）
gcc -O2 -Wall -o cv_capacitance.exe cv_capacitance.c -lm
./cv_capacitance.exe
```

Windows 下生成 `.exe`，在命令行直接运行。运行后控制台打印逐循环性能表与汇总（见第一章结果）。

## 三、逐模块讲解（对照 408 知识点）

### 模块一 `liion_cycle.c`

| 函数 / 结构 | 做什么 | 408 对应 |
|---|---|---|
| `read_curve()` | `fgets` 逐行、`sscanf` 解析两列，动态扩容存点 | 文件 I/O、字符串处理 |
| 动态数组 `realloc` 翻倍 | 每条曲线点数不固定，容量不够就翻倍 | **顺序表**，均摊 O(1) |
| `parse_index()` + `cmp_index()` | 从文件名抠列序号，用 `qsort` + 函数指针按列序排序 | 排序算法、**函数指针**比较器 |
| `midpoint_voltage()` | 线性插值求 50% 最大容量处的电压（中点电压） | 数值分析（插值） |
| 配对逻辑 | 充电曲线暂存，遇放电合成循环；并校验"放电起点电压 ≤ 充电终点电压(容差0.2V)"判定是否同循环 | 线性扫描、条件状态机 |
| 汇总统计 | 平均 CE / 平均 ΔV / 首末保持率 | 基础统计算法 |

> 两个模块共享同一套工程范式：**解析仪器/导出文件 → 动态数组存点 → 数值计算 → 排序/输出**。
> 数学方法上也是一对互补：模块一是**统计与插值**（CE、保持率、中点电压），模块二是**积分**（梯形法则）。一个项目同时覆盖数值方法的两条主线。

## 五、模块二：超级电容器 CV 分析（**本人 CHI600E 实测数据**）

### 5.1 数据是什么

- **仪器**：CHI600E 电化学工作站（辰华），循环伏安法（Cyclic Voltammetry）
- **体系**：水系电解液超级电容器，电位窗口 −0.8 ~ +0.8 V
- **规模**：12 组曲线，每组 4000 个数据点（电位 V / 电流 A）
- **实验设计**：
  - **扫描速率梯度** 8 组：0.002 / 0.005 / 0.01 / 0.02 / 0.05 / 0.1 / 0.2 / 0.5 V/s（2M H₂SO₄）
  - **电解液筛选** 4 组：0.5M H₂SO₄ / 1M HCl / 1M KOH / 2M H₂SO₄（固定 0.1 V/s）

> ⚠️ **面试口径要准**：原始文件夹名写的是"锂离子实验"，但从电解液（HCl / H₂SO₄ / KOH）和电位窗口（±0.8 V）看，实测体系是**水系电解液超级电容器**，不是有机体系的锂离子电池（锂电是 LiPF₆ 有机电解液、0~4.2 V 窗口）。
> 简历和面试里一律说"**超级电容器循环伏安测试**"或"水系电解液电化学表征"，**不要说成锂离子电池**——说错体系是硬伤，比不说更扣分。

### 5.2 物理原理（三个公式讲清楚）

双电层电容由 CV 曲线积分求得：

```
1) 电荷量    Q = ∫ I dt = (1/v) · ∫ I dE        （因为 dE/dt = v，故 dt = dE/v）
2) 梯形法则  ∫ I dE ≈ Σ (Iₖ + Iₖ₊₁)/2 · (Eₖ₊₁ − Eₖ)
3) 电容      C = Q / ΔV
```

为什么取"正向扫描半周"积分？一次 CV 是三角波扫描（低→高→低），完整的闭合回路净电荷为零，必须取**单个扫描方向**（从 Low E 扫到 High E）的积分才有物理意义。程序里自动定位电位极小值与极大值的索引，切出正向半周。

### 5.3 运行结果（真实输出）

```

    scan rate      Q (C)      C (F)   保持率
    0.002 V/s    1.192714   0.745446   100.0%
    0.005 V/s    1.128525   0.705328    94.6%
    0.01  V/s    0.848406   0.530254    71.1%

    0.05  V/s    0.405547   0.253467    34.0%

[B] 电解液筛选（固定 0.1 V/s，按电容排序）

```

### 5.4 为什么这组结果是可信的（面试能讲的物理）

结果不是数字游戏，两个趋势都符合教科书规律：

1. **倍率性能衰减**：扫速从 0.002 → 0.5 V/s，电容保持率掉到 5.7%。原因是扫速越快，离子来不及扩散进活性炭微孔，只有外表面参与电荷存储 → 有效电容下降。这是超电的**固有规律**，所有文献的 rate capability 曲线都长这样。
2. **电解液排序 2M H₂SO₄ > 1M HCl > 0.5M H₂SO₄ > 1M KOH**：
   - H⁺ 离子半径最小、迁移率最高 → 酸性体系整体优于碱性（KOH 垫底，因 K⁺ 半径大）
   - 同种电解液浓度越高电导越大 → 2M H₂SO₄ > 0.5M H₂SO₄

**面试金句**：「我的分析结果和文献规律一致，这反过来验证了原始测试数据本身是可靠的——做算法的人，第一步是判断数据能不能信。」

### 5.5 局限（诚实说，反而加分）

- 原始数据未记录**活性物质负载量**，所以只能算出电容 C（F），**算不出比电容（F/g）**
- 因此跨扫速对比用的是**归一化保持率**（以最低扫速为 100%），这个指标不依赖质量，是论文里的标准做法
- 面试官问"为什么不报比电容"，直接答上面两点，比硬编一个数值强

### 5.6 输出文件

- `cv_rate_capacitance.csv` — 扫速 / 点数 / 电荷 / 电容 / 保持率（**画散点图就是论文里的 rate capability 图**）
- `cv_electrolyte.csv` — 电解液排名（画柱状图）

### 5.7 数据校验（已做，故作记录）

曾用 Origin 导出的多列对比表（含手打列名 `0.5mol h2so4`/`1mol hcl`/`1mol koh`/`2MOL H2SO4`）与原 CHI 仪器文件**各算一遍电容**，4 条电解液结果逐位吻合（如 2M H₂SO₄ = 0.142769 F），验证解析管道无错位、积分取的是同一扫描分支。另用间隔 11 天的重测数据做重复性验证：电极重制致绝对电容差一个数量级，但电解液性能排序不变，故本项目统一采用归一化保持率而非绝对电容。

## 七、面试怎么讲（话术）

**HR/技术官问："这个项目做了什么？"**

> "我做了一套电化学数据的 C 语言分析工具，两部分。一部分处理锂离子电池的恒流充放电数据——就是本人实测的，有液态和固态两只电池。我写了程序自动把充放电曲线配对，逐圈算库仑效率、容量保持率、还有极化电压。液态那组首圈效率 89% 升到稳定 99%，容量保持率 94.5%。另一部分处理超级电容器的循环伏安数据，也是我自己用 CHI600E 测的，用梯形积分算双电层电容，做了倍率和电解液的对比。"

**追问："数据哪来的？"（必问，答好是加分）**

> "都是我自己处理的一手数据。锂电那部分是恒流充放电测试导出来的比容量-电压曲线；超电是 CHI600E 工作站跑的循环伏安。我专门没用网上下载的公开数据集当主项目，因为一手数据面试才敢展开讲、才经得起追问。"

**追问："库仑效率怎么算的？"**

> "库仑效率就是这一圈放出来的电量除以充进去的电量。充电曲线和放电曲线我按列序配对，放电容量除以充电容量就是当圈的 CE。首圈低是因为 SEI 膜成膜消耗了一部分锂，后面稳定到 99% 以上，这是正常规律。"

**追问："极化电压是什么、怎么算？"**

> "极化电压反映电池内阻和极化大小。我取充电曲线和放电曲线在 50% 容量处的电压，两个中点电压一减就是 ΔV。液态电池平均 0.15 V 左右，固态那组因为充电数据导出不完整我没法配对比，就只报了放电层面的指标，没有硬凑。"

**追问："为什么用 C 不用 Python？"**

> "两个原因：一是 BMS 跑在 MCU 嵌入式环境上，本身就是 C；二是我 408 复习时数据结构全用 C 写，这个项目正好把顺序表、排序、插值这些知识用到了真实场景。"

**追问："超级电容器那段数据是你自己测的吗？"**

> "是我自己上手做的。用 CHI600E 电化学工作站跑循环伏安，做的是水系电解液的超级电容器，电位窗口正负 0.8 伏。我设计了两组对照：一组是 8 档扫描速率，从 0.002 到 0.5 伏每秒，看倍率性能；另一组是固定 0.1 伏每秒扫 4 种电解液，做电解液筛选。每组 4000 个点，一共 12 组。"

**追问："电容怎么算出来的？"**

> "CV 曲线积分。核心是 Q 等于电流对电位积分再除以扫速，因为 dE/dt 就是扫速 v，所以 dt 换成 dE 除以 v。积分用梯形法则，取正向扫描的半周——完整一圈的闭合回路净电荷是零，必须取单个方向才有意义。然后 C 等于 Q 除以电位窗口。"

**追问："你怎么确定你的结果是对的？"**（这道是分水岭，答好直接拉开差距）

> "我做了两层验证。第一层是管道验证：同一批测量，我用原始 CHI 文件和 Origin 导出的多列对照表两种格式各算一遍，四个电解液的电容值逐位完全吻合——这一步是排除数据解析串列、积分取错扫描分支这类低级错误，做数据处理最容易翻车的地方就在这。
>
> 第二层是实验验证：隔了 11 天我又重测了一次，结果绝对电容差了十几倍，因为电极重制了、活性物质负载量变了。但电解液的性能排序完全没变，相对值也落在同一区间。所以我在项目里从头到尾只用归一化保持率、不报绝对电容——负载量未知的时候，绝对值没有跨批次可比性。"

**追问："为什么不报比电容（F/g）？"**

> "原始文件没记录活性物质负载量，算不出来。所以我用归一化保持率，以最低扫速或最优电解液为 100%，这个指标不依赖质量，也是论文里的标准做法。硬编一个 F/g 出来反而是假的。"

**追问："结果说明什么？"**

> "两个趋势都符合规律。倍率方面，扫速越快电容越低，0.5 伏每秒只剩 5.7%，因为离子来不及扩散进活性炭微孔，只有外表面参与储能。电解液方面，2M 硫酸最好、氢氧化钾最差，因为氢离子半径最小迁移最快，钾离子半径大。我的分析结果和文献一致，这也反过来说明原始测试数据是可靠的。"
