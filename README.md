# 电化学数据分析工具集（C 语言）

两个用 C 语言编写的小工具，用来分析我自己做实验得到的电化学数据：

| 程序 | 分析对象 | 数据来源 | 核心方法 |
|---|---|---|---|
| `liion_cycle.c` | 锂离子电池恒流充放电（GCD） | 本人实测数据（液态 / 固态各一） | 充放电曲线配对，计算库仑效率、容量保持率、极化电压 |
| `cv_capacitance.c` | 超级电容器循环伏安（CV） | 本人 CHI600E 实测数据 | 梯形数值积分求电荷量与双电层电容 |

两个程序均不依赖第三方库，纯标准 C 实现，约 500 行。

## 为什么写这个

做电池相关实验时积累了一些原始数据，但手头的商业软件（Origin 等）不便于批量、可复现地处理。于是用 C 把几个常用指标（库仑效率、容量保持率、极化电压、双电层电容）自己实现一遍，既能直接处理自己的数据，也把动态数组、排序、插值、数值积分这些编程基础用到了真实场景里。

### 实现要点

- **文件解析**：`fgets` / `sscanf` 读取 CSV 与仪器文件头
- **动态数组**：`realloc` 翻倍扩容存不定长数据点（顺序表，均摊 O(1)）
- **排序**：`qsort` + 函数指针比较器，按列序排列曲线
- **数值方法**：线性插值求中点电压；梯形法则积分求电荷量

## 模块一：锂离子电池 GCD 循环分析（`liion_cycle.c`）

### 数据

数据来自两份 Excel 导出的恒流充放电曲线，每只电池若干循环，每条曲线是「比容量(mAh/g) – 电压(V)」两列。

- **液态电解液电池（Sheet1）**：5 个完整充放电循环，电压窗口 2.4–4.3 V，可逆比容量约 85 mAh/g。
- **固态电解质电池（Sheet2）**：导出数据以 4 条放电曲线为主，充电曲线导出不完整，电压窗口偏窄（2.4–3.0 V），因此只能做放电层面的分析。

注：Sheet1/液态、Sheet2/固态的对应是按电压窗口推断的（液态有机电解液稳定窗口约 4.3 V，固态通常更窄），当时实验记录不全。若对应反了，只需交换两个目录名，程序逻辑不受影响。

### 方法

1. **库仑效率 CE** = 放电容量 ÷ 充电容量（每圈各算一次）
2. **容量保持率** = 第 N 圈放电容量 ÷ 首圈放电容量
3. **极化电压 ΔV** = 充电曲线中点电压 − 放电曲线中点电压（各取 50% 容量处，线性插值求得）

程序读入目录下的 CSV（文件名带 `_CH` / `_DI` 区分充放电），用动态数组存点、按列序排序后配对，再逐圈计算。当某条放电曲线的起点电压与对应充电曲线的终点电压相差超过容差（0.2 V）时，判定为"无对应充电"，只输出放电指标，不编造库仑效率或极化电压——这是处理真实实验数据时经常会遇到的情况。

### 运行

```bash
gcc -O2 -Wall -o liion_cycle.exe liion_cycle.c -lm
./liion_cycle.exe liion_data/liquid                 # 仅分析液态
./liion_cycle.exe liion_data/liquid liion_data/solid  # 液态 + 固态
```

### 结果（实测）

- 液态电池：首圈 CE 89.2% → 稳定 99.3%（平均 97.0%）；第 5 圈放电容量保持率 94.5%（85.80 → 81.10 mAh/g）；平均极化电压 0.152 V。
- 固态电池：充电曲线导出不完整，程序判定无对应充电，仅给出放电容量保持率 95.9%（85.20 → 81.70 mAh/g）。

## 模块二：超级电容器 CV 电容分析（`cv_capacitance.c`）

### 数据

- 仪器：CHI600E 电化学工作站（辰华），循环伏安法（CV）
- 体系：水系电解液超级电容器，电位窗口 −0.8 ~ +0.8 V
- 规模：12 组曲线，每组 4000 个数据点（电位 V / 电流 A）
- 实验设计：
  - 扫描速率梯度 8 组：0.002 / 0.005 / 0.01 / 0.02 / 0.05 / 0.1 / 0.2 / 0.5 V/s（2M H₂SO₄）
  - 电解液筛选 4 组：0.5M H₂SO₄ / 1M HCl / 1M KOH / 2M H₂SO₄（固定 0.1 V/s）

注意：这部分原始文件夹名写作"锂离子实验"，但依据电解液（HCl / H₂SO₄ / KOH）与电位窗口（±0.8 V）判断，实测体系是**水系电解液超级电容器**，并非有机系锂离子电池（锂电为 LiPF₆ 有机电解液、0~4.2 V 窗口）。引用或展示时请按实际体系标注，避免混淆。

### 方法

双电层电容由 CV 曲线积分求得：

```
1) 电荷量   Q = ∫ I dt = (1/v) · ∫ I dE        （dE/dt = v，故 dt = dE/v）
2) 梯形法则  ∫ I dE ≈ Σ (Iₖ + Iₖ₊₁)/2 · (Eₖ₊₁ − Eₖ)
3) 电容     C = Q / ΔV
```

一次 CV 是三角波扫描，完整闭合回路净电荷为零，因此只取单个扫描方向（从低电位扫到高电位）的半周积分。程序自动定位电位极小/极大值的索引切出正向半周。

### 运行

```bash
gcc -O2 -Wall -o cv_capacitance.exe cv_capacitance.c -lm
./cv_capacitance.exe
```

### 结果（实测）

- 扫描速率 0.002 → 0.5 V/s，电容保持率从 100% 降至 5.7%（离子扩散受限，符合双电层电容的倍率特性）。
- 电解液排序：2M H₂SO₄ > 1M HCl > 0.5M H₂SO₄ > 1M KOH（H⁺ 迁移率最高，酸性体系整体优于碱性）。
- 结果与文献规律一致，可作为原始数据可靠性的交叉验证。

### 局限

原始数据未记录活性物质负载量，因此只报电容 C（F），不报比电容（F/g）。跨扫速对比统一采用归一化保持率（以最低扫速为 100%），该指标不依赖质量，是常见做法。
