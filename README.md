# 电化学数据分析工具集（C 语言）

两个用 C 语言编写的小工具，用来分析我自己做实验得到的电化学数据：

| 程序 | 分析对象 | 数据来源 | 核心方法 |
|---|---|---|---|
| `liion_cycle.c` | 锂离子电池恒流充放电（GCD） | 本人实测数据（液态 / 固态电解液各一只） | 充放电曲线配对，计算库仑效率、容量保持率、极化电压 |
| `cv_capacitance.c` | 超级电容器循环伏安（CV） | 本人 CHI600E 实测数据（12 组 × 4000 点） | 梯形数值积分求电荷量与双电层电容 |

两个程序均不依赖第三方库，纯标准 C 实现，共约 500 行。`gcc -O2 -Wall` 直接编译，Windows（MinGW）/ Linux 均可。

---

## 一、为什么写这个

做电池实验积累了一些原始数据，但手头的商业软件（Origin 等）不便于批量、可复现地处理：每个循环要手动截一段、手动积分、再手动抄数，换一批数据全部重来。于是把几个常用指标（库仑效率、容量保持率、极化电压、双电层电容）用 C 自己实现一遍——既能直接处理自己的数据，也把动态数组、排序、插值、数值积分这些编程基础用到了真实场景里。

## 二、实验与数据

### 2.1 锂离子电池恒流充放电（GCD）测试

**测试方法**：恒流充放电（Galvanostatic Charge–Discharge, GCD）。导出的曲线为「比容量(mAh/g) – 电压(V)」两列，其中充电曲线电压随容量上升、放电曲线电压随容量下降。

**测试对象**：两只电池，电解液体系分别为液态与固态。

| 项目 | 液态电解液电池 | 固态电解质电池 |
|---|---|---|
| 源数据 | `锂电池数据.xlsx` Sheet1 | `锂电池数据.xlsx` Sheet2 |
| 循环数 | 5 个完整充放电循环（5 充 + 5 放） | 4 条放电曲线 + 1 条充电曲线（充电侧导出不完整） |
| 电压窗口 | 2.4 – 4.3 V | 2.4 – 3.0 V |
| 可逆比容量 | 约 85 mAh/g | 约 85 mAh/g（放电侧） |
| 数据点数 | 9036 | 9028 |

**预处理流程**：原始 Excel 是宽表格式（一条曲线占两列，15 条曲线并列），不能直接喂给程序。用 Python + openpyxl 按列对切分、剔除空行后，每条曲线存成一个 CSV：

```
锂电池数据.xlsx（Sheet1 / Sheet2，宽表）
        │  Python + openpyxl：按列对切分、剔除空行
        ▼
liion_data/liquid/Sheet1_curveNN_CH.csv   ← NN = 原表列序，CH = 充电 / DI = 放电
liion_data/solid/Sheet2_curveNN_CH.csv
        │
        ▼
liion_cycle.c 扫描目录下全部 *.csv，按列序排序后自动配对分析
```

CSV 表头统一为 `Capacity_mAh_g,Voltage_V`。拆分脚本是一次性处理，未随仓库提供；CSV 本身已作为分析输入入库。

**未记录的实验参数（如实说明）**：导出文件里没有电流密度（C-rate）、电解液组分与浓度、电极活性物质负载量、电极面积、电池型号等信息。因此本项目**只给相对指标**（库仑效率、容量保持率、极化电压），不报绝对容量、能量密度或比容量标称值——这些在缺少负载量与电流密度时无法严谨给出。

**液态 / 固态的对应关系**：Sheet1 = 液态、Sheet2 = 固态，依据是两表电压窗口差异：液态有机电解液（LiPF₆ 碳酸酯体系）电化学稳定窗口可达约 4.3 V，与 Sheet1 完整的 2.4–4.3 V 窗口一致；固态电解质稳定窗口通常更窄，与 Sheet2 受限的 2.4–3.0 V 相符。原始实验记录保存不全，此对应关系已与实验者本人核对确认。若日后发现反了，只需交换 `liquid/` 与 `solid/` 两个目录名，程序逻辑不受影响。

### 2.2 超级电容器循环伏安（CV）测试

| 项目 | 内容 |
|---|---|
| 仪器 | CHI600E 电化学工作站（上海辰华） |
| 方法 | 循环伏安法（Cyclic Voltammetry） |
| 体系 | 水系电解液超级电容器 |
| 电位窗口 | −0.8 ~ +0.8 V（ΔV = 1.6 V） |
| 电解液 | 0.5 M H₂SO₄ / 1 M HCl / 1 M KOH / 2 M H₂SO₄ |
| 数据规模 | 12 组曲线，每组 4000 个数据点（电位 V / 电流 A） |

**实验设计（两组对照）**：

1. **扫描速率梯度（8 组）**：0.002 / 0.005 / 0.01 / 0.02 / 0.05 / 0.1 / 0.2 / 0.5 V/s，固定 2M H₂SO₄ → 考察倍率性能
2. **电解液筛选（4 组）**：0.5M H₂SO₄ / 1M HCl / 1M KOH / 2M H₂SO₄，固定 0.1 V/s → 考察电解液种类与浓度的影响

**重复性测试（2 批次）**：另有一组间隔 11 天的重测数据（`origin_multi_0428_4elec.txt` / `origin_multi_0509_3elec.txt`），其间电极经过重制，用于验证相对排序是否稳定，详见第七章。

**数据文件**：`cv_data/` 下 14 个文本文件，均为 CHI 原始导出格式——开头是仪器参数头部（`Init E (V)`、`High E (V)`、`Low E (V)`、`Scan Rate (V/s)`、`Sensitivity (A/V)` 等），其后是 `Potential/V, Current/A` 列标题与数据区。程序解析头部拿参数、跳过列标题读数据。

**体系归属说明**：原始文件夹名写作"锂离子实验"，但从电解液（HCl / H₂SO₄ / KOH）和电位窗口（±0.8 V）判断，实测体系是**水系电解液超级电容器**，不是有机系锂离子电池（锂电为 LiPF₆ 有机电解液、0 ~ 4.2 V 窗口）。本仓库统一按"超级电容器循环伏安"标注，引用或展示时也请按实际体系写，避免混淆。

## 三、分析方法

### 3.1 锂离子电池 GCD 指标

1. **库仑效率 CE** = 放电容量 ÷ 充电容量（每圈各算一次；首圈偏低、稳定后趋近 100%）
2. **容量保持率** = 第 N 圈放电容量 ÷ 首圈放电容量（量化衰减）
3. **极化电压 ΔV** = 充电曲线中点电压 − 放电曲线中点电压（各取 50% 容量处，线性插值求得）

其中中点电压取「50% 最大容量」处的电压，用线性插值在实测点之间求值：

```
对相邻两点 (cₖ, Vₖ)、(cₖ₊₁, Vₖ₊₁)，求 c = 0.5·c_max 处的 V：
V = Vₖ + (Vₖ₊₁ − Vₖ) · (c − cₖ) / (cₖ₊₁ − cₖ)
```

**处理流程**：

```
本人实测 GCD 数据（Excel → 拆分为每条曲线一个 CSV）
        │
        ▼
 ① 读取（解析文件名 _CH / _DI，动态数组存 比容量 / 电压两列）
        │
        ▼
 ② 分类（电压随容量上升 = 充电；下降 = 放电）+ qsort 按列序排序
        │
        ▼
 ③ 配对（充电曲线 → 其后紧邻的放电曲线，合成一个循环）
        │
        ▼
 ④ 计算（线性插值求 50% 容量处中点电压；逐循环算 CE / ΔV）
        │
        ▼
 ⑤ 汇总（平均 CE、平均 ΔV、放电容量保持率；液态 vs 固态对比）
```

**配对的一致性校验**：真实数据经常出现曲线缺斤少两，所以配对时加了一道校验——若某条放电曲线的起点电压高出对应充电曲线的终点电压超过容差（0.2 V），说明两者电压窗口不自洽、不属于同一循环，程序即判定为"**无对应充电**"，对该条只输出放电容量与保持率，**不计算库仑效率与极化电压**。宁可少报指标，也不编一个物理上说不通的数出来。

### 3.2 超级电容器 CV 电容

双电层电容由 CV 曲线积分求得：

```
1) 电荷量    Q = ∫ I dt = (1/v) · ∫ I dE        （因 dE/dt = v，故 dt = dE/v）
2) 梯形法则  ∫ I dE ≈ Σ (Iₖ + Iₖ₊₁)/2 · (Eₖ₊₁ − Eₖ)
3) 电容      C = Q / ΔV
```

**为什么只取单程（半周）积分**：一次 CV 是三角波扫描（低电位 → 高电位 → 低电位，CHI 三段式顺序为 `Init E → Low E → High E → Init E`），完整闭合回路的净电荷为零，必须取**单个扫描方向**的积分才有物理意义。程序自动定位电位极小值与极大值的索引，切出 `[idx_min, idx_max]` 这段正向半周做积分。

## 四、程序实现

### 4.1 公共结构

两个程序共用同一套工程范式：**解析仪器/导出文件 → 动态数组存点 → 数值计算 → 排序 → 输出 CSV**。数学方法上互为补充：模块一是**统计与插值**（CE、保持率、中点电压），模块二是**积分**（梯形法则）。

### 4.2 `liion_cycle.c`

| 函数 / 结构 | 做什么 |
|---|---|
| `read_curve()` | `fgets` 逐行读、`sscanf` 解析两列数值，动态扩容存点 |
| 动态数组 `realloc` 翻倍 | 每条曲线点数不固定（从 204 到 2655 点不等），容量不够就翻倍 |
| `parse_index()` | 从文件名中抠出列序号（如 `Sheet1_curve03_DI.csv` → 3） |
| `cmp_index()` | `qsort` 的比较器（函数指针），按列序排列曲线 |
| `read_dir()` | 扫描目录下 `*.csv`，按 `vol[末] > vol[首]` 判定充/放电 |
| `midpoint_voltage()` | 线性插值求 50% 最大容量处的电压 |
| 配对逻辑 | 充电曲线暂存，遇放电合成循环；并校验"放电起点电压 ≤ 充电终点电压 + 0.2 V" |
| `analyze()` / 汇总 | 平均 CE、平均 ΔV、首末容量保持率 |

### 4.3 `cv_capacitance.c`

| 函数 | 做什么 |
|---|---|
| `grab_double()` | 从 CHI 头部的 `"Scan Rate (V/s) = 0.1"` 这类行里抠出参数 |
| `read_cv_file()` | 解析文件头 + 逐行读数据点（`in_data` 标志位识别头部/数据区分界） |
| 动态数组 `realloc` 翻倍 | 存 4000 个点，容量不够就翻倍 |
| 极值定位循环 | 一次线性扫描找出 `idx_min` / `idx_max`，切出正向半周 |
| 梯形法则积分 | `Σ (Iₖ + Iₖ₊₁)/2 · ΔE`，除以扫速得电荷量 |
| `cmp_cap_desc()` | `qsort` 比较器（函数指针），电解液按电容降序排名 |

### 4.4 实现要点

- **文件解析**：`fgets` + `sscanf`，纯标准库，不依赖 CSV 解析库
- **动态数组**：`realloc` 翻倍扩容存不定长数据点（顺序表，均摊 O(1)）
- **排序**：`qsort` + 函数指针比较器
- **数值方法**：线性插值求中点电压；梯形法则积分求电荷量

**结果解读**：

2. **电解液排序 2M H₂SO₄ > 1M HCl > 0.5M H₂SO₄ > 1M KOH**：H⁺ 离子半径最小、迁移率最高，因此酸性体系整体优于碱性（KOH 垫底，K⁺ 半径大）；同种电解液浓度越高电导越大，故 2M H₂SO₄ > 0.5M H₂SO₄。

两个趋势都与文献规律一致，这既说明数据本身可用，也说明解析与积分管道没有出系统性错误（另见第七章的两层校验）。

## 七、数据校验

积分、取半周、多列文件解析这些环节最容易悄悄出错（串列、取错扫描分支），所以专门做了两层交叉验证。

### 7.1 解析管道验证（同一批数据的两种导出格式对照）

同一批测量数据，分别用**原始 CHI 仪器文件**（`cv_data/elec_*.txt`）和 **Origin 导出的多列对照表**（`cv_data/origin_multi_0428_4elec.txt`，含手打列名 `0.5mol h2so4` / `1mol hcl` / `1mol koh` / `2MOL H2SO4`）各算一遍电容。4 条电解液的结果逐位吻合（如 2M H₂SO₄ = 0.142769 F）。这一步排除了数据解析串列、积分取错扫描分支这类低级错误——做数据处理最容易翻车的地方就在这里。

### 7.2 重复性验证（间隔 11 天重测）

用间隔 11 天的第二批重测数据（`origin_multi_0509_3elec.txt`）重复同样计算：由于期间电极经过重制，活性物质负载量变化，绝对电容相差一个数量级；但**电解液之间的性能排序完全不变**，相对值也落在同一区间。

这也是本项目跨扫速、跨电解液对比统一采用**归一化保持率**（以最低扫速 / 最优电解液为 100%）而不是绝对电容的原因：负载量未知时，绝对值不具备跨批次可比性。

> 需要说明的是，7.2 的两批数据里只有 4/28 那批的原始 CHI 文件与 Origin 表同时存在，5/9 那批只有 Origin 表，因此 7.1 的逐位对照只在 4/28 这批上完成。

## 八、已知局限与后续可扩展

- **样本量有限**：液态电池 5 圈、固态电池 4 条放电曲线，结论主要作方法演示，不足以讨论衰减规律。

- 极化电压目前用线性插值取中点，后续可改为在单调区间内二分查找。
